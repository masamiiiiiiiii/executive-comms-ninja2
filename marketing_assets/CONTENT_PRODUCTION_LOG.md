## 4. 日本語コンテンツ執筆ルール（学習済み）

> 詳細は `marketing_assets/JAPANESE_CONTENT_GUIDELINES.md` 参照

### 4-1. 禁止事項（発見済みの問題点）

| 問題 | 詳細 | 対策 |
|---|---|---|
| `——`（全角ダッシュ） | AI生成臭。日本語ユーザーに違和感を与える | 句点・読点・文分割に置き換え |
| `문장`（韓国語混入） | ハルシネーション。「文章」と字形類似による誤生成 | 出力後に必ず日本語チェックを実施 |
| 3点箇条書きの多用 | AI的な構成感が出る | 文章中に溶かす |
| 「〜においては」「〜という観点から」 | 書き言葉AI臭 | より簡潔な表現に置換 |

### 4-2. 構成フォーマット（日経ルポ型・確立済み）

```
1. 冒頭フック（前回との連続性 or 逆張り発言）
2. 結論先出し（スコアと評価帯）
3. データ章（数字の内訳と強みの分析）
4. 深掘り章（タイムラインの「決定的な瞬間」）
5. 構造的逆説（看板と実態のミスマッチ）
6. 普遍化・読者への示唆（反面教師 or 正解例）
7. 締め（短く、余韻を残す。CTAに繋げる）
```

## 5. X投稿パフォーマンス分析（学習済み）

### 最高インプレッション獲得パターンの条件

| 要素 | 内容 |
|---|---|
| **固有名詞** | 人名・事件名を冒頭に置く（誰が・何が即判断できる） |
| **具体的数字** | スコア・%・億円など（信頼性と興味を同時に担保） |
| **看板との落差** | 「神様」「元祖」などの肩書と弱点の対比 |
| **情報ギャップ** | 「まったく逆だった」など、読まないと分からない余白 |
| **ハッシュタグ** | 3つ以内。固有名詞系 + ExecCommsNinja + シリーズ名 |

### パターン別の向き不向き

| パターン | 特徴 | 向いているオーディエンス |
|---|---|---|
| A（数字×オチ型） | 情報量多め、バランス型。クリック動機が明確 | **認知拡大・新規獲得向き** |
| B（一点突破型） | 詩的・謎かけ。熱量高いがリーチ狭い | コアファン・PR業界向き |
| C（皮肉型） | 拡散狙いだが完結しやすく離脱も速い | すでに文脈を知っている層向き |
